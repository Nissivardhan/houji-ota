# houji changelog history

The Updater shows only the latest build (API/updater/changelogs/houji.md). Older builds are kept here.

## PixelOS 17.0 · 10 November 2026

**System**
- November 2026 Android security patch
- Signed with my own release keys (one clean flash needed if you're coming from a build before 10 November)

**Updates**
- System updates now come over the air: Settings › System › Software updates
- Small updates: from the previous build you download only the changes, not the full 4 GB
- Updates check by themselves in the background and after a reboot

**Battery**
- Fixed a timer that kept the phone from going into deep sleep after every wake

**Features**
- Seedvault encrypted backup, with its own app icon
- True black always-on display
- New Quick Settings tile: High touch polling (off by default, experimental)

## 10 November 2026, second build (first incremental update)

- Updates now check by themselves after a reboot

- Small updates: phones on the previous build download about 1.5 MB instead of 4 GB
