## PixelOS 17.0 · 15 November 2026 (beta 7)

- Settings › Battery › Battery health: how much charge the battery still holds compared with new, charge cycles and temperature
- Quick settings: new Charge limit tile to turn charging control on or off
- Settings › System › Auto restart when locked (off by default): restarts the phone after it stays locked for the hours you choose, so your data is encrypted again
- Settings › System › Seedvault backup now shows when the last backup ran, or that it failed
- Everything from beta 6: Install button fix, small updates from GitHub, install updates overnight
